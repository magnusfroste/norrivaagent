# Example files for the drop folder

Copy any of these into the folder you linked with `norriva link`, with
`norriva watch` running, and watch the dashboard.

- `resultatrapport-2026-09.csv` — a result report the way a bookkeeping
  system exports one (item; month; actual). The agent fills the *actual*
  column of `budget_lines` for January–September; the budget itself comes
  from the template the dashboard loads. Revenue runs a little under plan,
  subscriptions a little over, services well under — enough for an advisor
  to have something to say.
- `mote-volvo-2026-09-25.md` — a meeting note. Becomes a customer, a note,
  and an opportunity in *proposal*.
